# Onboarding cleanup

Verze 1.9.2 odstraňuje technický JSON náhled ze stránky pro založení klienta.

Veřejně viditelné zůstává pouze:

- potvrzení vytvoření klienta,
- veřejný rezervační odkaz,
- odkaz na administraci,
- krátká instrukce pro další krok.

Technický profil se nadále ukládá do databáze, ale nezobrazuje se uživateli na stránce.
